# Сквозной пример

Эталон полного прохода: требование → внутренний анализ → итоговый набор.

Этот пример показывает **решения**, а не только формат. Основная ценность — раздел «Решения группировки» и «Чего в наборе нет».

---

## Вход: требование

```
Применение промокода в корзине

Пользователь может применить промокод в корзине для получения скидки.

Основной сценарий:
1. Пользователь открывает корзину.
2. Пользователь вводит промокод в поле «Промокод».
3. Пользователь нажимает «Применить».
4. Скидка применена, итоговая сумма пересчитана.

Бизнес-правила:
БП-1. Промокод состоит из 6–12 символов: латинские буквы и цифры.
БП-2. Промокод применяется, если он существует и срок его действия не истёк.
БП-3. Промокод применяется, если сумма заказа не менее 1000 ₽.
БП-4. К одному заказу применяется не более одного промокода.
БП-5. Промокод одноразовый: повторное применение тем же пользователем невозможно.

Критерии приёмки:
AC-1. При корректном промокоде скидка отражена в итоговой сумме.
AC-2. При некорректном промокоде отображено сообщение об ошибке, сумма не изменена.
AC-3. Применённый промокод можно удалить из корзины.
```

Ключевых требований: 8 (БП-1…БП-5, AC-1…AC-3). Ориентир по объёму набора — 8–24 теста.

---

## Этап 1. Доменная модель (внутренний, не выводится)

| Элемент | Значение |
|---|---|
| Сущности | Корзина, Товар, Промокод, Заказ |
| Атрибуты промокода | код, срок действия, размер скидки, признак использования |
| Операции | применить промокод, удалить промокод |
| Связи | Корзина содержит Товары; Промокод применяется к Корзине |
| Зависимости | Сумма заказа ← состав товаров; применимость промокода ← сумма заказа |

Статусы промокода в требованиях не описаны — не придумываем.

## Этап 2. Анализ вариативности (внутренний, не выводится)

| Вопрос | Результат |
|---|---|
| Может отсутствовать? | Да — поле пустое → проверка валидации |
| Разные значения? | Короче 6, длиннее 12, кириллица, спецсимволы → БП-1 |
| Ограничения? | Формат, срок действия, минимальная сумма, одноразовость |
| Может изменяться? | Применён → удалён (AC-3) |
| **Влияет на другие сущности?** | **Да: сумма заказа зависит от состава корзины. Удаление товара может опустить сумму ниже 1000 ₽ при уже применённом промокоде — поведение в требованиях не описано** |

Последняя строка — находка этапа 2. Требования её не покрывают, конкретное поведение не выдумывается → уходит в вопросы, а не в тест-кейс.

---

## Решения группировки

**Объединено в один тест.** Все нарушения формата промокода (пусто, короче 6, длиннее 12, кириллица) → TC-002. Основание: одно бизнес-правило БП-1, одна реакция системы — ошибка формата. Четыре отдельных теста здесь были бы фрагментацией.

**Разделено на разные тесты.** Несуществующий, истёкший, ниже минимальной суммы, второй промокод, повторное применение → пять тестов. Основание: разные бизнес-правила с разными причинами отказа. Формально у всех «ошибка + сумма не изменена», но правило нарушается каждый раз своё — объединение скрыло бы непокрытое БП.

**Правило решения:** объединяем, когда совпадает *бизнес-правило*; разделяем, когда правила разные, даже если внешняя реакция похожа.

## Итоговый набор (то, что выводится)

### TC-001 – Применение корректного промокода

Приоритет: Высокий
Вид: Позитивный

Предусловия:
1. Пользователь авторизован.
2. В корзине товары на сумму не менее 1000 ₽.
3. В системе существует действующий промокод, ранее не использованный пользователем.

Шаги:
1. Открыть корзину.
2. Ввести действующий промокод в поле «Промокод».
3. Нажать кнопку «Применить».

Ожидаемый результат:
1. Корзина открыта.
   * Список товаров отображён.
   * Итоговая сумма отображена.
2. Значение введено в поле «Промокод».
3. Промокод применён.
   * Размер скидки отображён отдельной строкой.
   * Итоговая сумма уменьшена на размер скидки.

---

### TC-002 – Валидация формата промокода

Приоритет: Средний
Вид: Негативный

Предусловия:
1. Пользователь авторизован.
2. В корзине товары на сумму не менее 1000 ₽.

Шаги:
1. Открыть корзину.
2. Оставить поле «Промокод» пустым и нажать «Применить».
3. Ввести промокод длиной менее 6 символов и нажать «Применить».
4. Ввести промокод длиной более 12 символов и нажать «Применить».
5. Ввести промокод, содержащий символы вне латиницы и цифр, и нажать «Применить».

Ожидаемый результат:
1. Корзина открыта.
2. Отображено сообщение об ошибке: поле обязательно.
   * Итоговая сумма не изменена.
3. Отображено сообщение об ошибке: недопустимый формат промокода.
   * Итоговая сумма не изменена.
4. Отображено сообщение об ошибке: недопустимый формат промокода.
   * Итоговая сумма не изменена.
5. Отображено сообщение об ошибке: недопустимый формат промокода.
   * Итоговая сумма не изменена.

*Шаги 2–5 объединяют ввод и подтверждение, поскольку проверяется реакция на само значение. Правило «один шаг — одно действие» сохраняется там, где действия проверяются по отдельности.*

---

### TC-005 – Применение промокода при сумме заказа ниже минимальной

Приоритет: Средний
Вид: Негативный

Предусловия:
1. Пользователь авторизован.
2. В корзине товары на сумму менее 1000 ₽.
3. В системе существует действующий промокод.

Шаги:
1. Открыть корзину.
2. Ввести действующий промокод в поле «Промокод».
3. Нажать кнопку «Применить».

Ожидаемый результат:
1. Корзина открыта.
2. Значение введено в поле «Промокод».
3. Промокод не применён.
   * Отображено сообщение об ошибке: минимальная сумма заказа не достигнута.
   * Итоговая сумма не изменена.

---

### TC-008 – Удаление применённого промокода из корзины

Приоритет: Высокий
Вид: Позитивный

Предусловия:
1. Пользователь авторизован.
2. В корзине товары на сумму не менее 1000 ₽.
3. К заказу применён действующий промокод.

Шаги:
1. Открыть корзину.
2. Нажать кнопку удаления промокода.

Ожидаемый результат:
1. Корзина открыта.
   * Применённый промокод отображён.
   * Строка скидки отображена.
2. Промокод удалён.
   * Строка скидки не отображена.
   * Итоговая сумма возвращена к значению без скидки.

## Вопросы на уточнение

Выводятся отдельно от набора:

1. Что происходит с применённым промокодом, если после удаления товара сумма заказа опускается ниже 1000 ₽?
2. Сохраняется ли применённый промокод при выходе из корзины и повторном открытии?

---

## Чего в наборе нет и почему

| Не создано | Причина |
|---|---|
| «Поле "Промокод" отображено в корзине» | Полевой тест — проверка входит в TC-001 как часть сценария |
| «Кнопка "Применить" отображена» | Button-only антипаттерн без действия |
| Отдельные тесты на каждое нарушение формата | Одно бизнес-правило БП-1 → один тест TC-002 |
| «При удалении товара промокод отменяется» | Поведение в требованиях не описано → вопрос, а не тест |
| Тест на скидку в 0 ₽ | Такого правила в требованиях нет — это была бы галлюцинация |
